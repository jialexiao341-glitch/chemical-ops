# 评测数据与证据说明

本目录仅保留复测说明、固定题集和原始数据。历史阶段验收、重复评估摘要和已完成清单已删除；当前运行方式见 [Agent 运行说明](../Agent只读任务运行说明.md) 和 [任务队列运行说明](../数据库任务队列运行说明.md)。

## 原始证据

[评测原始证据归档](评测原始证据-20261009.zip) 保存原有 22 份 JSON、JSONL 和 XML 及其 `归档清单.json`。内容覆盖 Agent、RAG、权限和旧队列样本；旧 RabbitMQ 数据只供历史追溯，不能作为当前 MySQL 队列验收。

为保留 STAR 历史指标出处，归档内的 `historical-markdown-sources/` 另保存 8 份被引用文档的原始字节快照；路径及 SHA256 见 `清理保留证据清单.json`。这些快照是历史来源，不是新的验证结果，也不作为当前操作说明。原有归档成员保持不变。

需要查看证据时，将所需成员解压到临时目录，避免把旧 Markdown 再放回当前文档目录：

```powershell
Expand-Archive -LiteralPath 'docs/evaluation/评测原始证据-20261009.zip' -DestinationPath 'tmp/evaluation-evidence'
```

独立保留的 `rag_eval_summary_mixed200.json` / `rag_eval_results_mixed200.jsonl` 是固定 200 题的历史结果；新题集和优化复测是不同验证范围，不合并为一个指标。`live-query-*.json`、`intent-routing*.json`、`query-plan-schema.json` 为各自用例的原始查询与路由数据，文件名更晚不代表其覆盖范围包含此前全部能力。

工程化原始记录保存在 `../evidence/` 的 JSON 和截图：接口负载、Redis 缓存、监控权限、通知载荷、真实模型 smoke 和受控并发各自保留分母、环境及限制。它们不构成生产容量、外部通知送达或真实业务效果证明。

## 固定题集与复测入口

- `agent-business-v1-cases.json`：Agent 固定场景。
- `rag-20261009-before_cases.jsonl`：原 200 题的证据快照。
- `rag-generalization-100-20261009_cases.jsonl` 及 manifest：100 条新问题。
- `rag_golden_200.jsonl`、`rag_golden_hard60.jsonl`、`rag_golden_mixed200.jsonl` 及 manifest：供现用 RAG 评测读取的历史冻结输入；对应的历史题集生成脚本已移除。

固定输入仍被测试和脚本依赖，不按重复报告删除。业务模型评测入口见 [复测运行说明](业务场景与任务可靠性评测运行说明.md)。新实验使用独立输出路径；结果失败、跳过与模型错误必须保留，不覆盖已有原始证据。
