## 通用约定

- 需要登录的接口使用 `Authorization: Bearer <access_token>`；`POST /api/v1/auth/login` 为取得令牌的入口。逐接口的权限要求应以路由依赖和服务端校验为准。
- 参数 schema、必填项和模型约束以本页“请求/响应模型字段”及运行时 `/docs` 为准。路径变量使用 `{...}` 表示。
- 常见 HTTP 错误：`401` 未认证、`403` 无权限、`404` 资源不存在、`409` 状态冲突/幂等冲突、`422` 参数验证失败、`5xx` 服务端错误；单个端点实际返回码以 OpenAPI 和代码为准。
- 写请求的幂等要求受环境配置与中间件规则影响；生产环境若开启强制幂等需传 `Idempotency-Key`。登录及 AI 流式接口为明确豁免项。
- `multipart/form-data` 上传和 SSE 流式响应按端点实际媒体类型处理。

## 流式与文件接口注意事项

- `/api/v1/ai/chat/stream` 返回 SSE；按服务端事件协议消费增量和结束事件，不能按普通 JSON 一次性解析。
- `/api/v1/files` 使用上传请求体定义的媒体类型；上传、元数据查询、下载与业务附件绑定是不同操作。
- `/api/v1/files/{file_id}/download` 的响应可能是二进制流或对象存储响应，实际行为取决于文件存储配置。
