# 剩余整改设计

## 授权与目标
用户已批准增量整改方向，并明确授权当前会话自主详细设计、实施、验证与分批提交，跳过逐次设计审批。以 docs/项目问题与后续工作.md 第 10 节的剩余项为范围；不把新增预测、自动审批或自动付款纳入本轮。保留既有业务权限、状态机、模板和确认写入边界。验收以实际执行结果为准。

## 数据与安全
1. 历史重复来源订单保留全部业务来源、履约与财务关联。新建显式 legacy_source_duplicate 标记及审计，仅迁移时对历史重复组中非最早记录标记；生成 source_comparison_guard（非历史例外时等于来源比价 ID），唯一索引强制新单不能再次使用来源。标记不进入请求 Schema，不允许普通业务接口修改。新部署同样应用约束。若发现来源真实有误，仍另行审计纠正，不为过索引清空来源。
2. 全局 ASGI 请求体计量：JSON 写请求默认 1MiB，multipart 上限为文档限额加 1MiB，按接收块检查，不依赖 Content-Length；超限统一 413，不缓存超限内容。保留幂等同键异参保护。
3. 可信代理只由 Uvicorn 显式允许列表处理，应用不自行信任 XFF；增加共享 NAT 单账号锁隔离和伪造 XFF 测试。权限缓存以 Session 请求/事务为界，flush、commit、rollback 和显式角色写入失效；审计从请求上下文提取 IP/UA。
4. 领用选项、效期预警提供有上限的分页及关键字查询；旧调用兼容但同样有最大条数。供应商发货/质量列表使用一次 JOIN 组装，查询数不随页大小增长。

## 时间与执行边界
统一应用 UTC naive 存储、MySQL 连接会话 UTC、API 时间明确标识 UTC，前端转换 Asia/Shanghai。日期区间使用业务时区边界转换，不能按 UTC 日期误筛。历史时间仅对能够证实来源时区的列提供 dry-run 迁移清单；不对混合来源数据盲目减八小时。高开销 DB 阶段从 async 入口移入线程池，以完整阶段为边界且同一 Session 不并发使用；模型等待前释放事务。

## Agent
- 语义理解只从 Prompt + Understanding.slots 输出条件；服务端只校验权限、候选归属、版本、范围、确认及工具契约，不新增问法关键词补丁。
- 产品与询价候选由共用 PendingChoice 契约处理，记录候选 ID、类型、版本和选择上下文；批次持久化该状态，续跑时服务端验证用户选择来自当前候选。成功子任务保留且重验，失败/阻塞任务按依赖续跑。
- 历史按 token/字符预算裁剪最近上下文并保留明确目标、已验证对象和待选候选；不把摘要当权限或业务证据。读取历史优先校验权限/证据指纹，避免重复执行昂贵业务查询。
- 我的查询复用现有列表模板，提供本人任务列表/状态筛选/取消/回看。导出只包含当前用户仍可访问的已核验结果，CSV 做公式注入防护和结果上限。
- 草稿 patch 接口使用 confirmation_id + preview_version，锁定本人 PENDING 确认，白名单字段、领域 Schema 重新校验、重算 hash/对象快照、版本递增、旧版本不能确认；不直接创建或提交业务单据。
- 删除会话先取消未完成任务、清理队列可执行项及草稿确认状态，再删除关联消息；保留必要业务/安全审计，不删除已经确认创建的采购申请。无会话任务采用明确 TTL 清理。
- 数值白名单之外用字段/指标关联测试补齐保真评估；冻结样本与 oracle SHA 进入离线 CI，不伪造真实模型业务质量。

## 前端
所有视觉结构复用产品列表、现有抽屉、业务弹窗及来源悬浮窗。主数据选择器服务端搜索并按已选 ID 补回名称；通用原因弹窗处理必填、loading、防双击与焦点；所有停用/删除说明真实动作并确认。共享列表移除/实现死参数，提取重复脚手架；工作台按流式、轮询、会话职责拆分。流式 Markdown 缓存、合帧和滚动节流，键盘 IME 不误发，菜单焦点/图表替代文字/窄屏抽屉完成验收。保持中文单语言定位，隐藏无实际翻译的切换，内部状态码通过现有字典显示。登录图片用构建压缩保留内容，路由保留 hash，部署文档明确回退策略，不为改变路由模式增加迁移风险。

## 工程与验收
依赖锁文件只记录实际解析版本并可复现安装；容器提供 API/前端/Worker/MySQL/Redis/Qdrant/对象存储/反代，生产 TLS 与密钥 fail-closed，测试恢复使用独立数据库和卷。保留本机既有数据与凭据，不推送、不公开发布。离线门禁包括后端、类型、前端、冻结题集；真实外部依赖与模型只在已配置时执行并记录真实结果。浏览器以现有页面逐条验收，无法获得生产 TLS/标注数据等外部事实则记录未验证条件，不虚构完成。
