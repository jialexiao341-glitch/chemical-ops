# ChemicalOps：化工采购运营与 AI 协同平台

**后端 / 全栈开发｜业务平台 + 大模型应用工程化**

**【技术栈】** Python、FastAPI、SQLAlchemy、MySQL、Redis、Vue 3、TypeScript、LangGraph、Pydantic、Qdrant、MinIO、Docker、Prometheus / Grafana、OpenTelemetry

**【项目简介】** 面向化工企业采购履约与运营协同场景，基于 **FastAPI + MySQL + Vue 3** 构建采购、订单、库存、质检及财务管理平台，融合 **Agent 工作流、化学品知识检索与统一模型服务**，支持跨角色业务流转、采购辅助查询、草稿预览及文档与 AI 长任务的异步执行。项目基于开发环境与合成业务数据完成专项验证。

**【核心要点】**

- **业务系统与权限设计：** 基于 **FastAPI、SQLAlchemy、MySQL 与 Vue 3** 实现采购履约及财务协同，结合 **RBAC、资源级权限校验与业务状态机**约束跨角色操作；通过 **Decimal、事务行锁及追加式版本审计**保障金额计算、额度占用及双人复核的一致性与可追溯性。
- **缓存优化与限流控制：** 基于 **Redis Cache Aside、TTL 与提交后版本失效**优化产品目录、产品定位及会话历史查询，结合权限校验防止缓存越权；通过 **Lua 原子计数**实现用户级限流，专项测试中数据库 **SELECT 次数降低约 33%**。
- **异步任务与故障恢复：** 基于 **MySQL 持久队列 + 独立 Worker**实现文档解析与 Agent 长任务异步执行，通过 **SKIP LOCKED、任务租约、Fencing 与 Checkpoint**支持任务原子领取、有限重试和断点恢复；结合 **asyncio、线程池及子进程隔离**处理并发取消与异常退出，验证旧任务状态覆盖防护机制。
- **AI 服务治理与 Agent 编排：** 基于 **LangGraph + Pydantic**构建只读 Agent 工作流，实现意图识别、工具调用、多轮澄清及证据核验；设计 **LLM Gateway**统一模型配置、超时控制、有限重试、并发限额、熔断及故障降级，固定合成任务真实模型首轮严格成功率达 **93.75%**。
- **知识检索与质量保障：** 基于 **MinIO + MySQL + Qdrant** 构建化学品文档解析、结构化存储与向量检索链路，通过 **CAS / 名称归一化、内容 Hash 及索引代次校验**解决实体歧义与索引一致性问题；基于 **100 条合成测试题**开展检索质量评估，可回答题 **Recall@6=95.00%、MRR@6=0.91、nDCG@6=0.93**。
- **运行观测与验证闭环：** 集成 **Prometheus / Grafana、OpenTelemetry 与 Alertmanager**，实现 API、数据库、任务队列及模型调用指标监控，支持告警触发、恢复与重复抑制；通过 **311 项专项回归测试**验证业务流程、Agent 执行及任务恢复机制，并完成受控真实模型并发验证。
