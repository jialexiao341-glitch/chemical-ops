# 交期催办门户协同

## 启用

本功能新增迁移 `059_delivery_followups.sql`。部署时先通过既有迁移流程备份并升级：

```powershell
.venv/Scripts/python.exe scripts/migrate_database.py status
.venv/Scripts/python.exe scripts/migrate_database.py upgrade
```

本轮开发未直接升级开发业务库。供应商须有启用的门户绑定、纯供应商门户角色及交期读取权限，否则首次发送会拒绝。

## 使用流程

1. 采购打开已下单或部分到货、仍有待收量的订单，点击“交期跟进”，核对正文并确认保存草稿。
2. 另行点击“发送至供应商门户”，核对供应商及正文后确认。保存草稿本身始终不会发送。
3. 供应商从站内通知，或“供应商门户 → 交期更新 → 催办记录”，查看并正式回复。回复说明必填，预计到货日期可选；填写日期会同时更新订单及未收明细的交期，留空仅记录回复。
4. 采购从回复通知或订单“催办记录”查看结果。每条催办仅正式回复一次；再次跟进须准备新草稿。
5. 已保存草稿也可从本人提案 Inbox 跳回订单继续发送。发送或回复重试返回原结果；修改已回复内容会被拒绝。

发送重新核对当前订单事实及草稿版本。日期、交期、收货数量等变化时须重新生成预览。回复要求当前仍有待收数量；结束订单保留可授权查看的历史，不允许新回复。通知正文仅提示有催办或回复，跳转后仍重新校验权限与供应商绑定。

前端针对性测试为订单目录的 `followup-proposal.test.ts` 和 `followup-send.test.ts`；并执行该应用的 `vue-tsc --noEmit --skipLibCheck`。Windows 沙箱临时目录不能原子替换时，可将进程 TEMP/TMP 指向项目 `tmp/` 中专用目录，不修改依赖配置。

浏览器验收按蓝图统一策略另行收尾；本功能不发送邮件或 IM，不代替审批、正式下单或供应商发货通知。
