# AI 问答图表设计

## 当前可回答的问题

AI 聊天的只读业务查询来自 `backend/app/modules/ai/catalog.py`。普通汇总支持采购申请、采购订单、到货单、库存、质量验收、运营异常、财务对账、供应商，以及供应商报价、库存流水、财务发票和付款，共 12 类。报价和库存流水仅统计笔数；发票金额取含税金额，付款金额取登记金额，金额自动按币种分开。可按各数据集白名单中的状态、供应商、区域、产品、仓库等维度分组。明细查询支持已审批未询价申请、本周订单履约风险、产品批次可用库存、已验收订单财务进度、供应商报价与交期、库存变动与冻结原因，以及指定采购订单的跨模块追溯。实际结果仍受当前用户权限约束。

文档问答、问候、功能介绍、范围外问题和采购申请草稿预览没有统计行，不展示统计图。常规汇总目前没有按日期聚合采购订单金额的能力，因此不把普通金额汇总伪装成时间趋势。已有明细中的审批日期、报价日期、库存变动日期和库存有效期可以绘制真实日期序列。

## 图表映射

| 查询类别 | 图表 | 口径 |
| --- | --- | --- |
| 常规汇总，按状态、验收结果、优先级、异常类型等低基数维度 | 环形图 | 占比来自返回的指标值 |
| 常规汇总，按供应商、区域、产品、仓库等维度 | 横向条形图 | 长名称易读；最多显示前 10 项 |
| 常规汇总，按有效期分组 | 折线图 | 按实际有效期排序 |
| 常规汇总，不分组 | 单项条形图 | 显示真实汇总值，不生成没有分母的占比 |
| 已审批未询价申请 | 优先级环形图、审批日期折线图 | 同一批申请的两个视角 |
| 本周订单履约风险 | 风险类型条形图、供应商风险明细条形图 | 一条明细可同时命中多种风险，不用环形图暗示互斥占比 |
| 产品批次可用库存 | 仓库可用量条形图、批次可用量条形图 | 按产品和计量单位分别绘制 |
| 已验收订单财务进度 | 未完成环节条形图、订单金额对比条形图 | 金额按财务币种分别绘制；环节可重叠 |
| 供应商报价与交期 | 报价日期折线图、报价与实际交期对比条形图 | 报价按产品、币种和报价单位分别绘制 |
| 库存变动与冻结追溯 | 变动类型环形图、每日净变动折线图 | 按产品和计量单位分别绘制；净变动不是期末余额 |
| 指定采购订单跨模块追溯 | 环节状态环形图、关联记录条形图 | 无权限环节不进入关联记录统计 |

## 布局和数据边界

聊天消息依次展示文字回答、图表、可展开的结构化数据和原有查询来源。桌面端每行最多两张图，窄屏单列。图表只依据后端 `query_trace.rows` 中当前用户有权看到的行绘制；历史会话使用已保存的同一份查询链路。返回行被截断时显示提示。金额绝不跨币种合计；库存数量绝不跨计量单位合计；旧库存汇总如果没有逐行单位，就只展示原始结果而不绘制数量图。

图表颜色沿用 `src/constants/chart.ts` 和运营总览图表。文字及结构化数据保留准确值，图表用于帮助比较，不替代原始回答。
