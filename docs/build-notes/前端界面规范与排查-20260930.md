# 前端界面规范与排查

更新日期：2026-09-30。范围：`frontend-design/apps/web-chemicalops` 的业务列表、筛选栏和表单弹层。保留 Vben / Ant Design 的导航、配色及交互组件。

| 项目 | 规则 | 实现入口 |
| --- | --- | --- |

| 表格 | 使用通用工具栏、分页、状态字典与数值等宽数字；长字段省略并保留组件提示 | 列表适配层及既有 Vxe 配置 |

## 排查发现及修复

1. 默认三列筛选将控件拉宽，产品与供应商页又使用固定宽度且禁止换行。现统一为有宽度上限、可换行的筛选栏，移除两页的独立宽度策略。
2. Vxe small 表格默认 12px、Ant Design 正文 14px，造成同一应用字体密度差异。现统一业务列表正文与字体栈，复查实际计算样式为 14px。
3. 退货页使用独立 Ant Table 和大标题，长原因令行距过大。现接入 Vxe 通用列表，提供状态筛选、搜索/重置、分页、刷新、列设置、全屏及明细展开；操作沿用原权限与业务接口。
4. 多个弹窗/抽屉只有固定宽度，部分表单固定两列/三列。现增加视口上限和响应式列数；宽表格仍允许表格内部滚动。
5. 有效期预警以 batch_id 作为行标识，同一批次分布在多个库存位置时产生重复主键警告。现以 batch_id、warehouse_id、location_id 组合区分行，不合并或删减返回数据。
6. 两字按钮自动插入空格导致“搜索”“刷新”等呈现方式不同。现统一关闭自动空格。
7. 有效期预警仍有独立分段控件挤在标题旁，与其他功能区不一致。现将预警窗口改为标准筛选栏中的选择器，统一搜索、重置、标题工具栏及自适应列表高度；全部列设置合理最小宽度并共同分配剩余空间，避免仅产品列被拉宽。

## 复查边界

本轮检查覆盖共享列表入口、源代码中的固定宽度与列数，以及上述浏览器页面。保留组件原有焦点、禁用、错误提示和主题样式；没有新增取消焦点轮廓的规则。未对所有权限角色、全部表单状态和每个弹窗的提交业务做端到端验证，也未重新运行后端全量测试。宽数据表在窄屏内横向滚动是保留的交互，不表示所有字段能同时显示。

后续列表优先通过应用的 `useVbenVxeGrid` 配置筛选，不再单独设置 `flex-nowrap` 或超宽输入。特殊报表与长明细可保留必要列宽，但应限制在表格自身的滚动容器中。
