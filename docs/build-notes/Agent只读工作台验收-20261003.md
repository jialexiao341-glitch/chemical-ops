# 只读采购 Agent 工作台交付与验收

> 版本：v1.7｜日期：2026-10-03｜范围：本地开发环境，未部署生产。

## 实现与入口

AI 工作台 `/ai/workspace` 原聊天输入框直接输入库存/报价问题，或从 `/` 菜单选择“采购只读查询”；独立页面和右上角入口已移除。启动及补充使用 202 API，立即取得任务编号/状态，后台以独立数据库会话执行。产品/询价候选、取消、步骤及结果来源嵌入助手回复，补充条件沿用底部输入框。AIMessage 保存任务引用而非复制业务证据；URL 的 `conversation` 参数和本人 GET API 恢复历史任务，刷新不重算业务数据。旧 `/ai/agent` 地址仅重定向到工作台。

权限/读取失败清除当前证据；请求世代、任务 ID 与 revision 拦截迟到响应，避免覆盖取消或其他任务。库存入口按产品/仓库进入原列表；报价入口按询价 ID 进入原详情。来源页面仍由原后端鉴权。

## 设计依据与复查

使用 awesome-design-md / frontend-design 的执行和复查流程，主参考为项目现有 Vben / Ant Design 界面。技能本地未包含其目录列出的 design-refs，故沿用既有主题，不声称使用未读取的外部参考。

- 颜色：沿用 `--foreground / --muted-foreground / --primary / --border / --card / --destructive`，与项目明暗主题共同变化，不引入独立调色板。
- 字体：继承项目字体；标题 26px、结果标题 17px、表格 13px、记录说明 12px。数量使用表格数字，分单位展示，不用模型改写金额。
- 间距：4px 基础，页面 24px、结果/输入块 20px、行 12px；窄屏页面 12px、块 16px；表格内部水平滚动。
- 组件：原生 form/fieldset/label/radio/details/table 语义，Ant Design 输入和按钮；焦点 2px 主题色描边，加载/禁用状态明确。无新增动效。

复查修正项：

1. 候选选择仅来源于最新强制等待步骤，普通追问不复用过期候选；也允许补充精确条件后重新查询。
2. 取消/刷新结果优先于旧响应；权限错误立即清除旧证据。
3. 不显示原始 JSON 或数据库表名，来源采用业务名称；历史结果标注步骤和快照时点，查询中不显示旧追问作为当前回复。
4. 首次启动改为立即返回编号，避免等待模型期间无法刷新或取消。
5. 不显示草稿“已提交/已批准/已下单”，不提供写入按钮。
6. 库存来源列表关闭初始无条件自动查询；写入表单条件后调用 submit，同步最近提交值并重载，避免显示条件和实际查询范围不一致。
