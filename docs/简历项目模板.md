**2026.05–至今｜ChemicalOps：化工采购运营与 AI 协同平台｜后端 / Agent 开发**

**【项目背景】** 面向化工采购履约与运营协同，基于 FastAPI + MySQL 构建覆盖采购、订单、库存、质检及财务对账的业务平台，集成 Agent 查询与 RAG 知识检索能力；基于合成数据完成开发与验证。

**【核心工作】**

- **业务履约：** 实现采购下单、库存扣减、质检入库及财务对账，通过 RBAC、业务状态机与事务行锁约束跨角色操作和并发库存变更；结合幂等键与操作审计防止重复落账，追踪关键业务状态变更。
- **Agent执行：** 面向订单追溯、库存核对及组合查询，基于 Python + Pydantic 自研 Agent Harness，实现规划执行循环、工具调度及参数、权限与证据校验；结合 MySQL 持久队列、Checkpoint、租约与 Fencing 实现故障恢复及取消隔离。
- **事件与监控：** 将供应商交期变更与事件记录同事务保存，通过业务状态校验、事件去重及通知权限过滤，生成交期变化、未交明细与在途到货摘要，关联订单待办并通知采购人员；基于心跳、检查点与 Token 预算，通过定时扫描和管理接口提供执行停滞、连续工具失败及预算风险诊断。
- **知识检索：** 面向化工产品选型及采购资料问答，基于 MinIO + Qdrant 构建 RAG + Wiki 知识库，实现文档解析、章节索引与混合检索；通过 CAS 实体归一、版本校验及证据引用处理产品歧义与知识更新，100 条合成测试题的可回答子集 Recall@6 达 95%。
- **缓存限流：** 针对产品详情高频查询，采用 Redis Cache Aside + TTL 与版本化失效控制缓存一致性，结合 Lua 原子计数实现请求限流；单并发、冷/热各 100 次请求测试中，API 进程 SELECT 总数由 304 降至 204。
