# ChemicalOps 项目简介与业务流程

## 项目简介

ChemicalOps 是面向企业化学品采购运营的管理平台。当前代码由 FastAPI 后端、Vue 3 管理端、MySQL 数据库组成，并可按配置连接 MinIO 对象存储与兼容 OpenAI/DeepSeek 的模型服务。系统以采购、供应商、到货、质量验收、库存、财务和运营处置为主要业务域，并提供系统权限、文件附件、通知、任务及 AI 工作台等支撑能力。

前端位于 `frontend-design/apps/web-chemicalops`；后端入口为 `main.py`，应用代码在 `backend/app`；表结构和迁移分别位于 `database/schema.sql` 与 `database/migrations`。接口文档根据运行时 OpenAPI 整理，完整字段以数据库 DDL 为准。

## 已实现业务范围

| 领域 | 代码可确认的能力 |
|---|---|
| 主数据 | 化学品、产品及单位、供应商资料的新增、查询、修改或停用；具体字段见数据库及接口文档。 |
| 采购 | 采购申请及审批流转；询价、供应商报价录入、报价比较及选定报价；采购订单创建、审批、下单、取消。 |
| 到货与质量 | 到货计划登记、收货确认；质量验收及结果提交；验收报告上传、明细级报告核对、产品检测标准版本和人工复核留痕。 |
| 库存 | 仓库/库位、入库、余额查询、冻结/解冻、流水；领料、调拨、盘点、退货、FIFO 出库与效期预警等端点。 |
| 供应商协作 | 供应商门户查看订单并确认或拒绝；补货申请与处理。 |
| 财务 | 对账、发票录入和人工审核、付款申请审批及人工登记已付款、采购结算确认。以上不表示已接入银行或税务系统。 |
| 运营协同 | 异常登记、任务与评论、站内通知、逾期扫描及任务运行记录、Dashboard 查询。 |
| 文件 | 文件上传、元数据查询、下载、关联业务附件。文件二进制内容按配置存储，数据库保留元数据/对象关联。 |
| AI 工作台 | 会话历史与流式对话、化学品资料问答、12 类白名单业务汇总及图表、明确订单号追溯、自然语言筛选、运营晨报及人工确认的采购申请草稿。报价和库存流水开放笔数统计；模型与检索能力依赖外部服务配置。 |
| 业务辅助分析 | 批次影响、财务差异、异常处置、MSDS 章节变化、供应商履约、报价变化、盘点差异、消耗观察和库位提示等只读分析，从相应业务页面打开并显示证据与限制。 |
| Agent 只读任务 | 后端 LangGraph 条件循环支持产品定位、库存查询、询价定位与报价比较四个只读工具；Pydantic 动作、RBAC/资源范围、多候选追问、MySQL 任务轨迹与版本校验续跑/取消已实现；AI 工作台聊天已集成库存/报价任务，直接输入目标即可启动；候选选择在回复内完成、补充条件使用原聊天输入框，支持会话历史恢复、取消及来源展示，202 接口支持立即返回编号与轮询；2026-10-03 新增隔离样本来源/数值场景 30/30 通过；真实模型固定集 16/16 是聊天集成前的历史结果，本轮未重跑；确认写入与故障恢复待开发，见 [运行与验收](Agent只读任务运行与验收.md)及[阶段验收矩阵](evaluation/Agent阶段0-3验收矩阵.md)。 |
| 系统管理 | 登录、个人信息/密码、用户、部门、角色和权限管理；登录防护与令牌失效行为由迁移和配置决定。 |

## 核心业务关系

```mermaid
flowchart LR
  MD[化学品/产品主数据] --> PR[采购申请]
  SUP[供应商] --> RFQ[询价与报价]
  PR --> RFQ
  RFQ --> PO[采购订单]
  SUP --> PO
  PO --> DEL[到货登记/收货]
  DEL --> QA[质量验收]
  QA -->|合格数量| INV[批次与库存余额]
  QA -->|异常/不合格| EX[运营异常/任务]
  INV --> ISSUE[领料/FIFO 出库]
  INV --> TRANSFER[调拨/盘点/退货]
  PO --> FIN[对账/发票/付款/结算]
  FILE[文件元数据/附件] -.关联.-> PO
  FILE -.关联.-> QA
  DASH[Dashboard] -.查询聚合.-> PR
  DASH -.查询聚合.-> PO
  DASH -.查询聚合.-> INV
```

图表示代码与表结构体现的业务关系，不代表每条流程都自动触发。各业务状态和守卫条件以具体接口实现为准。

## 关键时序

### 采购到库存（概念主链路）

```mermaid
sequenceDiagram
  actor U as 采购/仓库人员
  participant FE as Vue 管理端
  participant API as FastAPI
  participant DB as MySQL
  U->>FE: 创建或维护采购申请/询价
  FE->>API: 请求对应业务接口
  API->>DB: 校验并保存主表、明细及状态
  API-->>FE: 返回业务结果
  U->>FE: 录入报价、生成比较并选定报价
  FE->>API: 报价/比较/选定操作
  API->>DB: 保存报价与采购订单关联
  U->>FE: 登记到货并确认收货
  FE->>API: 到货登记/收货接口
  API->>DB: 更新到货记录
  U->>FE: 提交质量验收结果
  FE->>API: 质量结果接口
  API->>DB: 保存验收结论
  alt 可入库数量大于零
    U->>FE: 发起或确认入库
    FE->>API: 库存入库接口
    API->>DB: 写入批次/余额/流水
  else 发现质量或数量异常
    API->>DB: 记录异常或待处理事项（按具体流程）
  end
```

### 登录与带权限请求

```mermaid
sequenceDiagram
  actor U as 用户
  participant FE as 浏览器
  participant API as FastAPI
  participant DB as MySQL
  U->>FE: 提交用户名和密码
  FE->>API: POST /api/v1/auth/login
  API->>DB: 校验账号状态、口令及失败尝试策略
  API-->>FE: 返回认证结果/访问令牌
  FE->>API: 后续请求携带 Bearer token
  API->>DB: 校验令牌有效性并加载权限上下文
  API->>DB: 执行业务读写
  API-->>FE: 返回业务响应
```

### 文件上传及业务附件

```mermaid
sequenceDiagram
  actor U as 用户
  participant FE as 浏览器
  participant API as ChemicalOps API
  participant DB as MySQL
  participant OBJ as 配置的文件存储
  U->>FE: 选择文件
  FE->>API: 上传文件
  API->>API: 校验媒体类型/大小/文件特征（按配置）
  API->>OBJ: 写入文件内容（对象存储模式）
  API->>DB: 保存文件元数据
  API-->>FE: 返回文件标识
  FE->>API: 将 file_id 关联到业务资源
  API->>DB: 保存附件关联
  API-->>FE: 返回附件结果
```
