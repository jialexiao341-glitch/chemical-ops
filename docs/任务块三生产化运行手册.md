# 任务块三：生产化运行手册

本手册把生产化验收拆成可执行的检查。生产环境不使用仓库中的 `.env.example` 示例密钥，所有密钥通过部署平台 Secret 注入。

## 1. 可观测性与告警

### HTTP 链路

- 每个请求都会生成或透传 `X-Request-ID`、`X-Trace-ID`，响应中原样返回这两个响应头。
- 日志输出为单行 JSON，至少包含 `timestamp`、`level`、`logger`、`message`、`request_id`、`trace_id`；慢请求会带 `duration_ms`、`status_code`、`path`。
- 500 响应只返回通用提示，详细异常只进入后端日志；日志不得包含 API key、文件正文、JWT、密码或用户原始问题。

### 探针和指标

```text
GET /health          # 存活探针，不访问外部依赖
GET /health/ready    # 数据库、对象存储、扫描器配置就绪探针；失败返回 503
GET /metrics         # Prometheus 文本格式
```

关键指标包括：HTTP 请求量/状态码/耗时、慢 SQL、AI 请求成功/失败/耗时、文件解析、MinerU、ClamAV、后台逾期扫描。建议告警规则：5 分钟 HTTP 5xx 比例 > 2%、就绪探针连续 3 次失败、AI 失败率 > 10%、P95 请求耗时超过业务阈值、ClamAV 非 `CLEAN`/`INFECTED` 的不可用比例 > 0。

## 2. 数据库备份、恢复和迁移

备份使用事务一致性的逻辑备份，密码只通过 `MYSQL_PWD` 传给客户端，不出现在命令行：

```powershell
$env:PYTHONPATH = "backend"
python scripts/backup_mysql.py --output-dir backups/mysql --keep 14
```

建议每日全量备份、保留 14 天，备份文件复制到与应用主机不同的加密存储，并每月执行一次恢复演练。恢复必须在隔离库验证：

```powershell
$env:PYTHONPATH = "backend"
python scripts/restore_mysql.py backups/mysql/chemicalops_YYYYMMDD_HHMMSS.sql --confirm
```

恢复验收至少检查：表数量、迁移版本、演示/管理员登录、采购订单到库存的主链路、审计日志和附件元数据。生产迁移顺序固定为：备份 → 预检重复数据/外键 → 低峰执行 → 关键接口冒烟 → 观察指标；迁移失败时停止发布并恢复备份，禁止直接对生产执行 `database/schema.sql`（该文件会删除表）。

任务块二迁移脚本已经是 fail-closed：发现历史重复的未关闭异常时不会自动删除业务数据。当前开发库若仍有重复记录，应先由业务确认保留记录，再单独生成清理方案。

## 3. 文件与对象存储安全

- MinIO 的 documents/results 桶必须保持私有；应用通过后端鉴权下载，不向前端返回永久公开 URL。
- 生产 `FILE_STORAGE_BACKEND=minio`，`MINIO_ACCESS_KEY`、`MINIO_SECRET_KEY` 由 Secret 注入，不能写入代码或日志。
- 生产必须设置 `FILE_SCAN_ENABLED=true`，并确认 API 运行环境能调用 `clamdscan --stream`。扫描状态为 `UNAVAILABLE`、`TIMEOUT`、`ERROR` 时上传失败关闭；`INFECTED` 时拒绝上传。
- 上传验收覆盖：EICAR 测试样本被拒绝、正常 PDF/Office 文件可上传、超大文件拒绝、扩展名/MIME/文件头不匹配拒绝、解析失败不会让原始文件绕过鉴权。

## 4. 慢查询与容量

默认 `DB_SLOW_QUERY_MS=500`，日志只保留 SQL 类型摘要和耗时，不保留绑定参数。每次发布前用真实数据量验证看板、订单分页、文件附件和 AI 只读查询；记录 P50/P95/P99、吞吐、错误率和数据库连接池占用。发现慢查询后先查看索引/执行计划，再改查询或索引，禁止用无限制全量查询掩盖问题。

## 5. 发布清单

1. CI 通过：后端编译、数据库初始化、迁移预检、测试、依赖扫描、Bandit、前端构建和 `npm audit`。
2. 生产配置检查通过：`APP_ENV=production PYTHONPATH=backend python scripts/check_production_config.py`。
3. 备份成功且可读，发布窗口和回滚负责人已确认。
4. `/health/ready` 返回 `ready`，MinIO 两个私有桶存在，ClamAV 生产样本验证通过。
5. 关键接口冒烟、慢查询日志和指标采集正常，观察 15 分钟后再完成发布。
