# ChemicalOps 本地开发环境说明

## Python 环境

后端使用项目根目录下的 uv 虚拟环境：

```text
C:\self_project\ChemicalOps\.venv
```

当前环境基于 Python 3.11，后端依赖安装自 `backend/requirements.txt`。`.venv/` 和 `.uv-cache/` 已加入 `.gitignore`，不会提交到版本库。

## 首次创建环境

```powershell
cd C:\self_project\ChemicalOps
uv venv .venv --python 3.11
uv pip install --python .venv\Scripts\python.exe -r backend\requirements.txt
```

如果网络访问默认 PyPI 较慢，可以使用镜像：

```powershell
uv pip install --python .venv\Scripts\python.exe `
  --index-url https://pypi.tuna.tsinghua.edu.cn/simple `
  -r backend\requirements.txt
```

## 启动后端

推荐使用项目入口，命令更短：

```powershell
cd C:\self_project\ChemicalOps
uv run main.py run --env=dev
```

`dev` 环境默认监听 `127.0.0.1:8888` 并开启热重载；生产环境使用：

```powershell
uv run main.py run --env=prod
```

如果需要手动指定虚拟环境，也可以使用下面的等价命令：

```powershell
cd C:\self_project\ChemicalOps
& .venv\Scripts\python.exe -m uvicorn app.main:app `
  --app-dir backend --host 127.0.0.1 --port 8888
```

接口地址：

- Swagger：`http://127.0.0.1:8888/docs`
- ReDoc：`http://127.0.0.1:8888/redoc`
- 健康检查：`http://127.0.0.1:8888/health`

## 启动前端

```powershell
cd C:\self_project\ChemicalOps\frontend
npm install
npm run dev
```

前端地址：`http://127.0.0.1:3000/`。Vite 会将 `/api` 和 `/health` 代理到后端 8888 端口。

## 初始化演示账号

```powershell
cd C:\self_project\ChemicalOps
& .venv\Scripts\python.exe scripts\seed_demo_accounts.py
```

脚本会读取根目录 `.env` 的 `DEMO_DEFAULT_PASSWORD`，已存在账号不会重置密码。
