# ChemicalOps 业务流程与业务关系图

> 本文档根据 ChemicalOps 最新需求整理，项目定位为“管理系统为主、AI 为辅”的化工采购与供应商管理系统。
>
> 图表使用 Mermaid 编写，可在支持 Mermaid 的 Markdown 编辑器、GitHub 或文档平台中直接渲染。

## 1. 系统业务总览

ChemicalOps 的核心不是聊天，而是管理化工采购从需求提出到到货验收的完整过程。AI 作为嵌入式助手，帮助用户查询、提取、比较和生成草稿。

```mermaid
flowchart LR
    A[化学品与产品管理] --> B[采购申请]
    C[供应商管理] --> D[询价与报价]
    B --> D
    D --> E[报价比较]
    E --> F[采购审批]
    F --> G[采购订单]
    G --> H[发货与到货]
    H --> I[验收]
    I --> J[供应商评价]
    J --> C

    K[文件与知识库] -.提供产品和供应商资料.-> A
    K -.提供技术证据.-> D
    K -.提供验收依据.-> I
    L[权限、审批与审计] -.约束.-> B
    L -.约束.-> F
    L -.记录.-> G
    M[ChemicalOps AI 助手] -.辅助.-> A
    M -.辅助.-> B
    M -.辅助.-> D
    M -.辅助.-> E
    M -.辅助.-> J
```

## 2. 采购申请到到货验收流程

```mermaid
flowchart TD
    A([提出采购需求]) --> B[创建采购申请]
    B --> C[填写产品、规格、数量、预算和期望日期]
    C --> D{产品与技术要求是否明确}
    D -- 否 --> E[补充技术要求或请求产品确认]
    E --> C
    D -- 是 --> F[提交采购申请审批]
    F --> G{审批结果}
    G -- 驳回 --> H[修改申请或取消]
    H --> B
    G -- 通过 --> I[创建询价单]
    I --> J[选择目标供应商并发送询价]
    J --> K[录入供应商报价]
    K --> L{是否收到足够报价}
    L -- 否 --> M[补充供应商或延长询价]
    M --> J
    L -- 是 --> N[比较价格、MOQ、交期和付款条件]
    N --> O[选择报价并填写选择理由]
    O --> P[生成采购订单]
    P --> Q[提交采购订单审批]
    Q --> R{审批结果}
    R -- 驳回 --> S[修改订单或重新比较报价]
    S --> N
    R -- 通过 --> T[发送订单并等待供应商确认]
    T --> U[登记发货和预计到货]
    U --> V[登记实际到货数量和批次]
    V --> W[执行到货验收]
    W --> X{验收结果}
    X -- 合格 --> Y[完成到货并更新订单状态]
    X -- 部分合格 --> Z[记录差异并创建异常任务]
    X -- 不合格/待复检 --> AA[质量异常或退换货处理]
    Y --> AB[供应商评价]
    Z --> AB
    AA --> AB
    AB --> AC([流程结束])
```

## 4. 询价与报价比较流程

采购员可以将多家供应商的报价集中到一个询价单中，以统一维度进行比较。

```mermaid
flowchart TD
    A[采购申请明细] --> B[创建询价单]
    B --> C[设置产品规格、数量、交期要求和截止时间]
    C --> D[邀请多个供应商]
    D --> E1[供应商 A 报价]
    D --> E2[供应商 B 报价]
    D --> E3[供应商 C 报价]
    E1 --> F[标准化报价字段]
    E2 --> F
    E3 --> F
    F --> G[价格比较]
    F --> H[MOQ 比较]
    F --> I[交期比较]
    F --> J[付款条件比较]
    F --> K[历史交付与质量表现]
    G --> L[综合比较结果]
    H --> L
    I --> L
    J --> L
    K --> L
    L --> M[采购员选择供应商并填写理由]
    M --> N[生成采购订单草稿]
```

## 5. 文件与知识库流程

```mermaid
flowchart LR
    A[上传 TDS/MSDS/检测报告/报价单/资质文件] --> B[保存文件元数据]
    B --> C[记录来源、版本和有效期]
    C --> D[关联化学品、产品或供应商]
    D --> E[异步解析任务]
    E --> F[提取文本和关键参数]
    F --> G{人工确认}
    G -- 未确认 --> H[标记为待确认]
    G -- 已确认 --> I[写入结构化资料]
    I --> J[关键词检索]
    I --> K[后续可接入语义检索]
    H --> J
    C --> L[有效期检查]
    L --> M[过期或即将过期提醒]
```

文件内容存储在 MinIO，业务数据库保存文件元数据、关联关系和解析状态。AI 提取结果必须能够追溯到原始文件。

## 6. AI 辅助业务流程

AI 位于管理页面的辅助区域，可以读取用户有权限访问的业务数据，但不能绕过业务 API 直接修改数据库。

```mermaid
sequenceDiagram
    actor User as 用户
    participant Page as 管理页面
    participant Agent as ChemicalOps AI 助手
    participant Auth as 权限服务
    participant Tools as 只读业务工具
    participant DB as MySQL/文件资料
    participant Approval as 业务审批
    participant Audit as 审计记录

    User->>Page: 输入采购需求或业务问题
    Page->>Agent: 发送结构化上下文
    Agent->>Auth: 校验用户、角色和数据范围
    Auth-->>Agent: 返回授权范围
    Agent->>Tools: 调用产品、供应商、报价或订单查询工具
    Tools->>DB: 查询授权范围内的数据和文件元数据
    DB-->>Tools: 返回业务数据和来源
    Tools-->>Agent: 返回结构化证据
    Agent-->>Page: 返回检索、推荐、比较或分析结果
    Page-->>User: 展示结果和引用来源
    Agent->>Audit: 保存会话、步骤和工具调用

    opt 用户要求创建或修改业务单据
        Agent-->>Page: 生成采购申请/询价/订单草稿
        User->>Page: 检查并确认草稿
        Page->>Approval: 提交正式业务审批
        Approval-->>User: 返回审批状态
        Approval->>Audit: 记录审批和执行结果
    end
```

### 6.1 AI 典型使用场景

| 管理页面 | AI 辅助能力 |
|---|---|
| 产品管理 | 按名称、CAS、规格和技术参数检索产品 |
| 产品详情 | 提取 TDS/MSDS 参数，推荐替代产品 |
| 供应商管理 | 总结供应商资质、报价和交付表现 |
| 采购申请 | 从自然语言生成采购申请草稿 |
| 询价管理 | 推荐符合条件的供应商 |
| 报价比较 | 自动总结价格、MOQ、交期和付款条件差异 |
| 采购订单 | 生成订单草稿并检查字段完整性 |
| 运营看板 | 分析逾期、短交、质量和文件异常 |
| 报表中心 | 生成采购分析报告和价格趋势摘要 |

## 7. 权限、审批与审计关系

```mermaid
flowchart TD
    U[用户] --> UR[用户-角色]
    UR --> R[角色]
    R --> RP[角色-权限]
    RP --> P[菜单/API/数据范围权限]

    U --> PR[采购申请]
    PR --> PA{采购申请审批}
    PA -- 驳回 --> PR
    PA -- 通过 --> RFQ[询价与报价]
    RFQ --> PO[采购订单草稿]
    PO --> POA{采购订单审批}
    POA -- 驳回 --> PO
    POA -- 通过 --> E[订单执行]
    E --> D[到货与验收]

    U --> AI[AI 查询或草稿请求]
    AI --> AC{Agent 工具权限}
    AC -- 无权限 --> X[拒绝并记录]
    AC -- 只读 --> Q[执行查询]
    AC -- 生成草稿 --> Draft[返回待确认草稿]
    Draft --> PR
    Draft --> PO

    U --> Audit[系统审计日志]
    PR --> Audit
    PA --> Audit
    RFQ --> Audit
    PO --> Audit
    POA --> Audit
    D --> Audit
    Q --> Audit
    X --> Audit
```

## 10. 业务闭环摘要

```text
产品与化学品资料维护
  → 供应商和资质维护
  → 提出采购申请
  → 申请审批
  → 创建询价并收集报价
  → 比较价格、MOQ、交期和供应商表现
  → 选择供应商
  → 采购订单审批
  → 发货与到货登记
  → 验收与异常处理
  → 供应商评价
  → 价格、交付和质量历史沉淀

AI 在各个页面提供检索、提取、推荐、比较和报告辅助；
涉及正式写入的操作必须由用户确认并经过系统审批。
```
