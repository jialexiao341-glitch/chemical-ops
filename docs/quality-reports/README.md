# 质量报告流程材料

本目录的三份内部检验记录依据本地开发库中 `QA-26001`、`QA-26002` 的产品、批次和到货信息编写，用于验证报告上传、解析、字段核对和验收录入流程。检测数值为流程材料中的拟制内容，不是实验室实测结果，也不能作为质量放行依据。

报告正文保持业务文书的写法；材料用途及数据来源统一说明在本文件中。

| 验收单 | 关联报告 | 核对覆盖 |
| --- | --- | --- |
| `QA-26001` | 无水乙醇到货检验记录 | 批次一致；外观和鉴别与系统录入一致；纯度和水分待录入。 |
| `QA-26002` | 丙酮到货检验记录 | 批次一致；外观和鉴别与系统录入一致；纯度和水分待录入。 |
| `QA-26002` | 丙酮留样复核记录 | 批次一致；只包含纯度和水分，外观与鉴别未在本报告重复。 |

在本地开发库重跑关联和核对：

```powershell
.\.venv\Scripts\python.exe scripts\run_quality_report_flow.py
```

脚本仅允许开发环境运行；同名文件已关联时不会重复上传，但会再次调用已配置的 AI 模型执行核对。页面入口为“质量管理 → 质量验收 → 核对报告”。
