## 1. 本次实现范围

当前前端位于 `frontend/`，采用 React 19、TypeScript、Vite，首个增量包含：

- 登录页：调用 `/api/v1/auth/login` 获取 Bearer JWT。
- 当前用户恢复：刷新页面后调用 `/api/v1/auth/me` 恢复登录态。
- 运营总览：真实数据库聚合指标、采购折线图、订单状态环形图、供应商/成本条形图、风险等级图和库存预警可视化。
- AI 工作台：右下角悬浮球、可拖动 QQ 风格聊天窗、历史会话、快捷问题和附件上传；消息通过 `/api/v1/ai/chat/stream` 使用 SSE 增量渲染，结束后保留完整会话记录。
- 化学品管理：调用 `/api/v1/chemicals` 分页查询，并支持关键字查询。
- 服务状态：调用 `/health` 展示后端 8888 端口是否在线。
- 导航骨架：采购、仓储、质量、供应商和系统管理模块预留入口。

## 2. 配色方案

本次没有继续使用普通的蓝色后台模板，而是采用“工业运营控制台”方向：

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--ink` | `#102A3B` | 侧栏、标题和深色品牌基底 |
| `--mineral` | `#1AA994` | 主色、选中状态和正常趋势 |
| `--mineral-deep` | `#0B8478` | 主按钮和主要交互 |
| `--amber` | `#E0A044` | 库存预警和待处理提醒 |
| `--coral` | `#DF6A5F` | 严重风险和错误提示 |
| `--canvas` | `#F3F7F6` | 页面背景 |
| `--paper` | `#FFFFFF` | 卡片和表格容器 |

桌面端布局按参考图统一为深色侧栏、顶部账户区和冷白内容画布；仪表盘使用 4 张 KPI 卡片、趋势/状态栅格和订单/待办栅格。账户菜单保持在顶部层级，不参与内容流；采购订单详情使用右侧固定浮层，不挤压订单主表。AI 助手以右下角悬浮球打开约 780×620 的 QQ 式对话窗，历史会话栏约 218px；窄窗口自动切换为单栏登录和纵向助手布局。页面层级统一为业务浮层、账户区、AI 对话和模态框四级，避免右上角控件相互覆盖。

设计取向参考系统化企业软件的网格、密度和信息层级，同时用矿物绿和暖琥珀色强化化学品业务属性。与生成的概念图相比，正式实现减少了装饰性元素，让风险状态和操作入口更清晰。

## 3. 启动方式

在项目根目录执行：

```powershell
cd frontend
npm install
npm run dev
```

访问 `http://127.0.0.1:3000/`。Vite 会把 `/api` 和 `/health` 请求代理到 `http://127.0.0.1:8888`。

演示账号使用此前初始化脚本创建的账号，密码读取项目根目录 `.env` 中的 `DEMO_DEFAULT_PASSWORD`，不会硬编码到前端。

AI 助手使用当前登录用户的 Bearer JWT。后端从项目根目录 `.env` 加载 `OPENAI_API_KEY`、`OPENAI_BASE_URL` 和 `LLM_MODEL`；本地默认模型为 `deepseek-flash`。会话和消息已经持久化到数据库，前端选中文件后先以 `PRIVATE` 级别上传，再把文件 ID 交给 AI；TXT、CSV、Markdown、JSON、PDF、DOCX、XLSX、PPTX 会在权限校验和 10 MB 解析上限内截取正文，消息引用会记录来源定位；业务问题还会按当前用户权限加载实时 Dashboard 概览，订单/到货/库存问题最多补充 8 条明细。
聊天工作台的标题、会话预览和时间保持单行省略，正文与输入框采用更舒适的可读字号；发送区按钮固定小尺寸并禁止换行。AI 助手使用普通请求一次性接收完整回答，再展示查询依据和数据引用，不伪装成流式输出；执行状态调试面板不再展示给用户。

## 4. 生产构建

```powershell
cd frontend
npm run build
```

构建产物输出到 `frontend/dist/`。生产环境如果不使用同域反向代理，可以在 `frontend/.env` 中设置：

数量、金额和百分比统一经过 `frontend/src/utils/format.ts` 展示格式化：数据库的 `DECIMAL(18, 6)` 仍按原精度提交和保存，界面会去除无意义的末尾 0；采购履约中的计划到货、实收、短交输入会同时显示订单对应的计量单位，避免出现 `19.000000` 或无法判断单位的问题。

```env
VITE_API_BASE_URL=http://127.0.0.1:8888/api/v1
```
