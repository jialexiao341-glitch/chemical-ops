# 全栈审查覆盖清单

## 标记与边界

- **部分静态检查**：已阅读列出的代表性入口或函数；不表示本模块所有文件、分支及接口均已检查。
- **未检查**：尚未形成可核对的源码检查记录。
- **局部验证**：仅表示表中明确列出的测试或计算通过，不表示端到端验收完成。
- **待隔离验证**：需独立测试数据库、存储、浏览器或可控故障环境；不得连接现有业务数据库执行写入测试。

问题明细、证据及可信度见 [全栈架构与代码审查报告](全栈架构与代码审查报告.md)。本清单按现有源码模块和前端路由整理，条目状态不会因存在测试文件自动变为已验证。
