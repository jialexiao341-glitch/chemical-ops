# 采购来源唯一约束前置核对

自动迁移 052 已独立完成结算规则变更。本目录 SQL 不进入自动迁移发现，待历史订单来源核清后转为下一版本迁移。

本地核查发现比价单 383、中选报价 1494、采购申请 658 同时关联订单 325（PO-26001，COMPLETED）和 326（PO-26002，PARTIAL）。两单的供应商和来源均一致，已有履约，不能根据现有证据删除、取消、合并或改写来源。

当前应用以询价单、比价单行锁串行定标/下单，并在锁内检查来源订单，阻止新增重复单。直接数据库写入仍缺唯一约束保护，B-P0-01 不视为完全关闭。

处理前先核对两张订单的订单行、到货、验收、库存、发票和付款，记录真实来源；修正需在同一审计方案中保留历史，不能清空 source_comparison_id 规避约束。

核查 SQL：

```sql
SELECT source_comparison_id, COUNT(*) AS order_count,
       GROUP_CONCAT(id ORDER BY id) AS order_ids
FROM purchase_orders
WHERE source_comparison_id IS NOT NULL
GROUP BY source_comparison_id HAVING COUNT(*) > 1;
```

结果为空后，将本目录 SQL 作为新版本迁移交由 scripts/migrate_database.py upgrade 执行，使用工具默认备份流程。新部署也必须补此约束，不应长期依赖应用锁。
